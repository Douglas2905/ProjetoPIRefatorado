# Projeto Integrador — Refatoração Java

## Descrição

Este projeto foi desenvolvido como parte do Projeto Integrador, com o objetivo de organizar e refatorar um sistema Java, aplicando princípios de orientação a objetos e boas práticas de programação.

## Objetivos

- Separar as responsabilidades das classes.
- Aplicar princípios SOLID, especialmente o Princípio da Responsabilidade Única.
- Melhorar a organização e a manutenção do código.
- Facilitar a reutilização das regras de negócio.
- Preparar a estrutura do projeto para futuras evoluções.

## Tecnologias utilizadas

- Java
- Apache NetBeans
- Git
- GitHub
- Apache Ant

## Organização do projeto

O código-fonte está organizado em pacotes:

- `model`: contém as classes que representam os dados do sistema.
- `repository`: contém as classes responsáveis pelo armazenamento e recuperação dos dados.
- `service`: contém as regras de negócio.
- `app`: contém a classe principal para iniciar o sistema.

## Como executar

1. Clone ou baixe este repositório.
2. Abra o projeto no Apache NetBeans.
3. Aguarde o reconhecimento da estrutura do projeto.
4. Execute a classe principal `Main.java`.

## Testes

Os testes de funcionamento devem verificar as operações implementadas no sistema e confirmar que as regras de negócio estão funcionando corretamente.
